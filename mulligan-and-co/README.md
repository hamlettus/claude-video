# Mulligan & Co. — website

Landing page for a subscription service delivering **customised golf consumables**
(tees, glove, cap, polo, balls), personalised from a simple logo up to a full
custom design.

## Files

- `index.html` — the complete, self-contained landing page. No build step, no
  dependencies, no external assets. Open it in a browser or drop it on any static
  host (GitHub Pages, Netlify, Vercel, S3, etc.).

## Design

- **Palette:** deep pine-charcoal ground, warm chalk text, brass/gold accent, with
  turf green as a supporting tone — a dark, premium "members' club" feel.
- **Type:** high-contrast serif display, neutral sans body, mono for labels/specs
  (uses system-font stacks; no webfonts to load).
- **Themes:** ships dark by default with a designed light (parchment) theme; the
  toggle in the top-right overrides the OS preference.
- **Responsive** and respects `prefers-reduced-motion`.

## Note on the name

The name **Mulligan & Co.** is a placeholder and, at time of writing, conflicts
with an existing golf-apparel brand (mulligannco.com) operating in the same
custom-apparel niche. Run trademark/domain checks before committing to it.
